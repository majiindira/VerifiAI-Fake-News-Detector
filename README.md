# VerifiAI - Fake News Detector

## About
VerifiAI is a machine learning project
that analyzes news articles and predicts
whether their text resembles fake or real news.

## Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression

## Features
- News article input
- Fake/Real prediction
- Confidence score
- Probability breakdown
- Model performance metrics

## How to Run

1. Install dependencies:

   pip install -r requirements.txt

2. Train the model:

   python train_model.py

3. Run the application:

   streamlit run app.py
